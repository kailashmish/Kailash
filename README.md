# Kailash Mishra — Portfolio

Personal portfolio site (same structure/style as [Madhu Jha's portfolio](https://madhujha050.github.io/Madhu/)).

## Local development

```bash
cd kailash-portfolio
npm install
npm run dev
```

## Deploy to GitHub Pages

1. Create a **public** GitHub repo named `Kailash` under `kailashmish`.
2. Push this project to that repo.
3. Run:

```bash
npm run deploy
```

4. In the repo: **Settings → Pages → Deploy from branch → `gh-pages` → /(root)** → Save.

Your site will be live at:

`https://kailashmish.github.io/Kailash/`

Update LinkedIn URLs in `src/components/Hero.tsx`, `About.tsx`, `Footer.tsx` if needed.
